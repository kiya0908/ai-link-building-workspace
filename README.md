# AI Link Building Workspace

Local-first Chrome Extension workspace for AI-assisted backlink comment workflows.

## Stack

- WXT
- React
- TypeScript
- Zustand
- IndexedDB
- Manifest V3

## Architecture

- Injected sidebar UI
- Content-script DOM interaction
- Provider-based comment form abstraction
- Repository-oriented IndexedDB storage
- Replaceable AI provider interface
- Runtime message router scaffold

Business workflows are intentionally left for later tasks.
